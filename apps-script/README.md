# Apps Script — ยังไม่ใช่โค้ดใช้งานจริง

โฟลเดอร์นี้เตรียมไว้เก็บซอร์สโค้ดของระบบเจ้าหน้าที่ในระยะถัดไป ไม่ควรคัดลอกสคริปต์ sync เดิมโดยไม่ตรวจสอบก่อน เพราะยังไม่รองรับย้ายปลูกครบวงจร

งานที่จะพัฒนา: `auth`, `activity`, `tree-move`, `work-order`, `registry-sync`, `export-public-json` และระบบสำรองข้อมูล

การกำหนดสิทธิ์ของ Apps Script ต้องพิจารณา Google Workspace ของหน่วยงานและผู้ใช้จริงก่อน deploy
